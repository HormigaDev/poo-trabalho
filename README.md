# Projeto universitário POO - Biblioteca

Antes de começar instale as dependências do projeto rodando o comando:

```bash
npm install
```

Para executar as simulações das questões do projeto, basta rodar os comandos:

```bash
npm run q1 # Questão 1
npm run q2 # Questão 2
npm run q3 # Questão 3
npm run q4 # Questão 4
```
